# HU-06: Consulta federada interinstitucional de historial

**Estado:** terminada (API + pantalla `/consulta` + pruebas).
**Cobertura:** RF-05, RF-07, RF-11. **Prioridad:** Alta.

> Como funcionario de una universidad quiero consultar el historial de un estudiante de otra universidad, con el permiso de este, sin saber en qué servidor están los datos.

## 1. Qué se hizo y por qué

`GET /api/v1/federated/academic-history/{student_id}` con dos encabezados: `X-Node-API-Key` (la universidad que consulta) y `X-Student-Consent-Token` (el token de HU-04). La demo (`docs/DEMO.md`) ya mostraba este comportamiento con datos en el código; ahora lo hace la app final con **DynamoDB y los nodos reales**.

1. Se identifica a la universidad que consulta por su API Key (brecha B13).
2. Se valida el token (HU-07, ver `HU-07.md`).
3. El token trae el nodo de origen (`origin`): con él se lee el historial exacto, sin que quien consulta sepa dónde está (transparencia de ubicación; cierra la brecha B3 sin tabla de enrutamiento).
4. Se **recalcula la firma SHA-256** del historial y se compara con la guardada en HU-03: si alguien alteró una nota, responde 500 en vez de entregar datos falsos (cierra B6).
5. Se responde con el historial, promedio ponderado, créditos aprobados (sin repetir materias) y la fuente de datos (`X-Data-Source: Primary`; la réplica llega con HU-08).

Nunca se devuelven `password_hash` ni la clave. La pantalla `/consulta` permite hacerlo con clics.

## 2. Archivos
`src/app/routers/federated.py` (endpoint, conversión de `Decimal`, resumen), `src/app/main.py`, `src/app/static/consulta.html` y `consulta.js`, tarjeta en `inicio.html`, `tests/test_hu06_07_federated.py`.

## 3. Cómo probarlo
1. Haz HU-01 a HU-04 (universidad aprobada, historiales cargados, token generado **para esa misma universidad**).
2. En `/consulta` pega la API Key de la universidad, el código `20262678029` y el token; **Consultar historial**: aparece el expediente, el promedio y «Fuente de datos: Primary».
3. Prueba con un token de **otra** universidad aprobada: la consulta cruza universidades (el historial sigue en su nodo de origen).
