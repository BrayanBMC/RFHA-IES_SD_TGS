Carga de historiales

Sube los historiales de tus estudiantes a la red. Si un estudiante ya existe, se reemplaza. La clave que escribas para cada estudiante le sirve para entrar al portal.

Sincronizar

La que entregó el administrador al aprobar el nodo. Empieza por «rfha_».

Hasta 100 estudiantes por envío. Pulsa «Cargar ejemplo» para ver el formato.

Qué pasa al sincronizar

  1. Identificación. La API Key dice qué universidad eres; no puedes escribir datos de otra.
  2. Validación. Se revisan cédula, código, notas (0 a 5) y semestres.
  3. Firma. Cada historial recibe una huella SHA-256 para detectar alteraciones.
  4. Clave del estudiante. Se guarda solo su huella (PBKDF2), nunca la clave.
